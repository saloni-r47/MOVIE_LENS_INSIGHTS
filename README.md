# MOVIE_LENS_INSIGHTS
Movie_Lens SQL Data Analysis — A MySQL-based data analytics project that analyzes movie ratings, user behavior, movie popularity, genre performance, and rating trends using 15 SQL queries ranging from basic to advanced. The project demonstrates practical use of JOINs, aggregation, filtering, subqueries, CTEs, and window functions.
This project focuses on analyzing the MovieLens movie-rating dataset using MySQL. The analysis explores movie popularity, audience ratings, user behavior, genre performance, and rating activity over time.

The project contains 15 SQL questions ranging from Basic to Intermediate and Advanced levels and demonstrates practical SQL and data-analysis techniques.

Popular but relatively poorly rated movies
